# CSIS — Video Page

A single HTML page that plays `mp.mp4`, styled with the CSIS (Criminal Study Intelligent System) theme.

## Usage

Open `index.html` in a browser. Keep `mp.mp4` in the same folder as `index.html`.

## Files

- `index.html` — the page
- `mp.mp4` — the video (1680×720, 3 min 45 s)
